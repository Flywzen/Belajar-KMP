Aplikasi pertama dengan Kotlin Multiplatform, target Android, iOS, dan Desktop (JVM).

## Cara menjalankan
- Android: `./gradlew :androidApp:assembleDebug`
- Desktop: `./gradlew :desktopApp:run`
- iOS: buka folder `iosApp` di Xcode lalu Run.
