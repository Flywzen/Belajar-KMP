# Hands-on KMP

Latihan hands-on dari kelas. Baru pertemuan 2–4 yang dikerjakan di sini.

| Folder | Isi |
| --- | --- |
| `handson-pekan-2` | Coroutines, Flow operators, StateFlow counter |
| `handson-pekan-3` | Profile card, login form, daftar produk |
| `handson-pekan-4` | Counter, form state hoisting, Todo MVVM |

Setiap folder adalah proyek Gradle terpisah, buka satu per satu. File `shared/`, `androidApp/`, dan `iosApp/` di folder ini adalah proyek awal bawaan KMP.
