# Hands-on P3 — Compose Multiplatform Basics

Tiga latihan, dipilih dari menu aplikasi:

1. `Handson1ProfileCard.kt`: avatar bulat, nama bold, bio abu-abu dalam `Card`.
2. `Handson2LoginForm.kt`: username, password tersamar, dan tombol yang memanggil `onLogin`.
3. `Handson3ProductList.kt`: daftar produk dengan `Card`, `Row`, `Column`.

## Menjalankan
- Android: buka folder ini di Android Studio, jalankan modul `composeApp`.
- Desktop: `:composeApp:run` lewat Gradle.
- iOS: source set tersedia, tapi proyek Xcode belum ada.

Belum ada Gradle wrapper di folder ini.
